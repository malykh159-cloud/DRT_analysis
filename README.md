# DRT Analyzer 0.4.1

Разделы Frequency Range, Validation и Peaks можно раскрывать стрелкой;
по умолчанию они свёрнуты. Сворачивание сохраняет значения и не отключает
настройки. В Regularization → Advanced находятся Derivative order,
Scan log₁₀ λ min/max и Scan values. У каждого Bayesian-параметра, включая
Advanced, кнопка **?** открывает описание, влияние и практические рекомендации.

Локальное Windows desktop-приложение для анализа EIS методом распределения времён
релаксации. PySide6 + pyqtgraph, отдельное NumPy/SciPy ядро. Исходные измерения
сохраняются неизменными. Программа не назначает пикам физические механизмы.

## Быстрый запуск

Готовая portable-сборка: `dist/DRTAnalyzer/DRTAnalyzer.exe`.
Переносить нужно **всю папку DRTAnalyzer**, включая `_internal`, а не один EXE.
Python на целевом компьютере не требуется. Windows 10/11 x64.

Из исходников: двойной щелчок по `start.bat` или:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
python run.py
```

Установка для разработки (Python 3.11+, данная сборка проверена на 3.14.8):

```powershell
python -m venv .venv
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-dev.txt
python -m pip install -e . --no-deps
python -m pytest -q
```

Файлы также можно передать `python run.py file1.txt file2.xlsx`.
Зависимости текущей проверенной сборки зафиксированы в requirements*.txt.

## Работа с данными

1. **Import EIS** или перетащить один/несколько TXT/CSV/TSV/XLSX в окно.
2. Выбрать строку: Nyquist и Bode сразу показывают исходный спектр.
3. **Run analysis** применяет настройки справа; **Auto Analyze Selected** или
   **Auto All** используют воспроизводимый стартовый алгоритм.
4. Вкладки **DRT**, **Residuals / KK**, **Results / decisions**, **Warnings**
   содержат результат, параметры и принятые решения. `Ctrl`/`Shift` выбирают
   несколько строк для Compare DRT и экспорта.
5. Двигать/масштабировать графики можно мышью; двойной щелчок возвращает масштаб.
   В Compare DRT щелчок по образцу линии в легенде скрывает/показывает кривую.
   Наведение на оранжевый маркер пика показывает τ, f, γ и Rp; щелчок выбирает
   строку таблицы пиков. Ось DRT переключается между τ и частотой.

В разделе **FREQUENCY RANGE** включите **Use manual frequency range** и задайте
**f min / f max (Hz)**, например `0.1` и `1e4`. Границы включительны; минимум
8 точек. **Run analysis**, **Auto** и **Lambda Scan** применяют диапазон ко всему
расчёту, включая Lin-KK и автоматическую сетку τ. При Auto для нескольких файлов
сохраняется индивидуальный диапазон каждого файла. Снятие флажка возвращает
полный исходный диапазон. Вне выбранного окна исходные точки показаны серым;
Rp относится именно к выбранному окну. Границы и индексы точек сохраняются в
истории и табличных экспортах.

Выделите строки спектров или элементы истории и нажмите **Del**, либо используйте
**Remove selected spectra / variants**. `Ctrl`/`Shift` позволяют выбрать несколько
элементов. Удаляются только записи текущей сессии; исходные файлы на диске не
удаляются. После удаления текущего варианта выбирается предыдущий оставшийся
или первый следующий; после удаления всей истории остаётся исходный спектр.
Во время фонового расчёта удаление недоступно.

Рядом с каждым изменяемым параметром есть кнопка **?**. Она открывает русскую
справку: смысл параметра, влияние на результат и практические рекомендации.
Справка не блокирует основное окно. Для более близких пиков, например, описаны
условия уменьшения λ и расстояния детектора, а также риск принятия шума за пик.

При движении курсора строка над графиками показывает частоту. На **Nyquist**
это ближайшая измеренная точка по экранному расстоянию, с Re/−Im и отметкой
исключения из диапазона. На **DRT** частота вычисляется из координаты τ, либо
читается с частотной оси; показываются обе величины и интерполированная γ
выбранной кривой. На Bode/остатках частота берётся с горизонтальной оси.
Метка и вертикальный указатель помогают ориентироваться; в PNG указатели
курсора не включаются. На Compare скрытые кривые не участвуют в подсказке.

Один файл — один спектр. Распознаются frequency/freq/f/Hz, Re(Z)/Zre/real/Z',
Im(Z)/Zim/imaginary/Z'', включая явные `-Im` и `-Z''`. Поддерживаются UTF-8,
Windows-1251, Windows-1252, разделители `;`, табуляция, запятая и несколько
пробелов; десятичная запятая — при подходящем разделителе.
В XLSX нужен ровно один лист с распознаваемым спектром; несколько спектров
в одном файле не поддерживаются. Строки с ошибками не отбрасываются молча.

**Знак:** внутри используется Z = Re + j Im. Nyquist: x = Re, y = −Im.
По принятому условию спектры преимущественно ёмкостные: если отрицательных
ненулевых значений исходного мнимого столбца больше, он принимается за **Im(Z)**;
если положительных больше — за **−Im(Z)**. Решение автоматическое, без диалога,
для каждого файла отдельно, независимо от написания заголовка. Нули не участвуют
в голосовании; при равенстве используется знак заголовка (обычный Im по умолчанию).
Подсчёт ведётся по полному источнику **до** ограничения частот. Правило, счётчики
и исходный заголовок записываются в метаданные. Преимущественно индуктивные
спектры этим автоматическим правилом не поддерживаются. Оригинальные числа
не меняются; API-импорт по-прежнему позволяет явно задать `im_multiplier`.

NaN/Inf, неположительные/дублирующиеся частоты, нулевой комплексный импеданс,
меньше 8 точек или неоднозначные столбцы дают ошибку. Сортируется только копия;
о больших частотных пробелах и узком диапазоне выводится предупреждение.

## Методы и настройки

Tikhonov DRT с γ ≥ 0, Rs ≥ 0 и при обнаруженной ВЧ-индуктивности L ≥ 0.
RBF: Gaussian, C2/C4/C6 Matérn; производная штрафа 0/1/2, по умолчанию 2.
Auto shape задаёт FWHM базиса равной расстоянию между центрами в ln τ.
Сетка строится автоматически строго внутри [1/(2π fmax), 1/(2π fmin)].

Manual — полноценный режим исследования. Auto использует Gaussian, Manual shape (ε = 6),
порядок 2, rGCV на 41 λ от 10⁻⁸ до 10², Lin-KK и те же критерии пиков.
Auto не ищет физический механизм. Фактические λ/ε, знак, использованные точки,
диапазон индуктивности и предупреждения показаны в Results / decisions.
Настройки Auto сразу доступны для редактирования; следующий Run analysis создаёт
Manual-вариант. История хранит рассчитанные снимки; Undo/Redo и список истории
переключают их без повторного расчёта. Новая ветка после Undo заменяет redo-ветку.
Данные текущей сессии хранятся в памяти, автоматического восстановления нет.

λ: Manual, GCV, mGCV, rGCV, L-curve и paired k-fold. GCV-семейство оценивает
**линейную задачу без ограничений**, затем итоговая DRT решается с положительностью.
Это явно показанная surrogate-оценка, не точный GCV для constrained estimator.
L-curve и k-fold используют constrained fits. k-fold: 5 фиксированных folds,
seed 34054, обе компоненты одной частоты исключаются вместе.
Выбранное на границе значение λ требует просмотра чувствительности.

**Lambda Scan** рассчитывает полные варианты для заданного диапазона λ в фоне;
ползунок переключает кэшированные DRT, реконструкции, пики, Rp, residual RMS
и норму штрафа. Apply добавляет выбранный вариант в историю.

**Lin-KK:** комплексная взвешенная RC-регрессия с series L и опциональным
series capacitance. Выбор M по μ ≤ 0.85 с явным защитным нижним пределом
3 RC/декаду (эвристика приложения, редактируется справа). Порог Review по
relative RMS по умолчанию 2%. Compatible означает согласованность с тестовой
моделью; это не доказательство линейности, стационарности или причинности.
Inconclusive означает, что μ/ранг не позволяют уверенный вывод. Review никогда
не блокирует DRT. Ни Lin-KK, ни Auto не вырезают отдельные точки.

**ВЧ-индуктивность:** непрерывная ВЧ-группа с Im/|Z| > 0.002 обнаруживается
эвристически. В модель добавляется `jωL`, все точки сохраняются. Одной точке
или слабому/смешанному признаку сопутствует предупреждение. Низкочастотная
индуктивная петля может требовать другой модели; отрицательная γ в GUI отсутствует.

**Пики и Rp:** prominence по умолчанию 3% максимума γ, расстояние 0.15 декады.
Границы вкладов — локальные минимумы между пиками; сумма вкладов покрывает
полную DRT. Высота пика не равна сопротивлению. Граничный максимум помечается
как неразрешённый. Rp — интеграл γ d ln τ по измеренному окну; дальние процессы
и незавершённые хвосты делают оценку зависимой от диапазона.

## Импорт и ручные настройки (0.3.0)

Поддерживается TXT DRTtools без заголовка: ровно три числовых столбца — частота
(Гц), Re(Z), мнимая часть. Разделители: табуляция, пробелы, `;`, запятая.
Десятичная запятая допускается при другом разделителе. Правило большинства знаков
сохраняется. Дополнительно поддержаны UTF-16/UTF-32 с BOM.

Ручные поля доступны постоянно. Изменение λ включает Manual λ, изменение ε —
Manual shape, изменение границ частот — ручной диапазон. Загрузка истории
не переключает записанные режимы. По умолчанию shape Manual, ε = 6, включая Auto.
Одинаковое ε даёт разную ширину для разных базисов: проверяйте реконструкцию и
остатки; Auto shape подбирает ширину по шагу сетки.

## Как использовать Compare

1. Импортируйте минимум два спектра и рассчитайте их, например через Auto All.
2. Выделите строки в SPECTRA с Ctrl / Shift; Ctrl+A выбирает все строки.
3. Нажмите Compare DRT: откроется наложение текущих результатов файлов.
4. Переключайте ось τ / Frequency; нажимайте на легенду, чтобы скрыть кривую.

Нерассчитанные файлы пропускаются. Compare сравнивает разные файлы, используя
текущий вариант истории каждого файла. Справка также есть в Help → How to compare spectra.

## Экспорт и воспроизводимость

**Export → Export results and PNG plots** открывает общий диалог экспорта.
По умолчанию выбраны все рассчитанные спектры; можно переключиться на выделенные строки.

- XLSX: Summary, DRT, Impedance, Peaks, Raw source, Lambda selection, Settings;
  число пиков не ограничено, единицы указаны в заголовках.
- TXT: те же численные таблицы с табуляцией, включая настройки и диагностику.
- Отдельные PNG: выберите Nyquist, DRT, модуль/фазу Bode, остатки DRT/Lin-KK.
  По умолчанию включены Nyquist и DRT. Графики сохраняются для каждого файла.

Summary содержит только File, Rs, Rp total, λ и Rp каждого пика. Положения пиков
и диагностика остаются в подробных таблицах. Новая папка с меткой времени содержит
results.xlsx, txt/ и plots/ согласно выбору. SVG, CSV и JSON больше не предлагаются.

TXT использует полную стандартную float-печать; XLSX имеет обычную конечную
точность Excel. Экспорт таблицы Raw source не заменяет хранение исходного файла.
Логи: `logs/drt_analyzer.log`, ротация 3 × 2 MB. Нет облака и телеметрии.

## Проверка и portable build

```powershell
python -m pytest -q
python run.py --smoke-test --output artifacts/source_smoke
python scripts/validate_real_data.py
powershell -NoProfile -ExecutionPolicy Bypass -File .\build_portable.ps1
```

Сборка сначала запускает тесты, затем PyInstaller и отдельную проверку самого
EXE с синтетическими данными, Qt-графиками и экспортами. Результат:
`dist/DRTAnalyzer/`. Перед пересборкой закройте запущенный EXE. Внешний Windows
компьютер без Python в этой среде недоступен; перенос проверяется дополнительно
на целевой машине. Проверка EXE на этой машине использует собственный runtime.

Для выбора DLL сборка использует PATH только из `.venv`, базового Python и
Windows. `scripts/verify_bundle.py` проверяет происхождение нативных библиотек:
зависимости из посторонних Poppler/Conda и других инструментов приводят к ошибке
сборки. Это предотвращает конфликт `icuuc.dll` с QtCore. Результаты каждого
запуска сохраняются в отдельной папке `artifacts/portable_smoke_DRTAnalyzer_*`,
включая `native_dependencies.json`, `smoke_result.json`, `stdout.txt` и `stderr.txt`.
Ошибки импорта Qt также записываются в `logs/drt_analyzer.log` рядом с EXE.

`scripts/validate_real_data.py` проверяет все 35 примеров и SHA-256 до/после.
Он использует то же правило большинства знаков, что и GUI; это проверка
интеграции, а не физическая валидация экспериментов.
Отчёты находятся в `artifacts/real_data_validation/`.

## Ограничения

Bayesian DRT доступен в METHOD → DRT. Его блок настроек появляется между
REGULARIZATION и RBF. По умолчанию: Warm-up 1000, Samples 2000 на цепочку,
Chains 4, Seed 42, Credible interval 95%. Advanced закрыт; σ автоматически
оценивается по остаткам MAP. Run analysis / Auto Selected / Auto All учитывают
выбранный метод. Stop рядом с progress bar останавливает текущий sampler.

На DRT показаны posterior mean и поточечный credible interval. В Results / decisions
и Warnings проверяйте R-hat и ESS. Интервал условен на выбранные λ, базис и шум;
не включает неопределённость физической модели. Bayesian медленнее Tikhonov,
особенно при малом λ; результаты с плохой сходимостью доступны со статусом Review.
Подробности и источники: [Bayesian DRT](docs/BAYESIAN_DRT.md).

Reference-проверка: `python scripts/validate_bayesian_reference.py` сравнивает
posterior mean, пики, Rp и интервалы с закреплённым sampler pyDRTtools при
одинаковых матрицах и posterior. Импорт, экспорт и Tikhonov defaults не менялись.
Не реализованы circuit fitting, автоматическая физическая интерпретация,
ручное разделение пиков, проекты/БД и installer.

Формулы, численные соглашения и первоисточники: [docs/MATHEMATICS.md](docs/MATHEMATICS.md).
Архитектура и порядок работ: [docs/IMPLEMENTATION_PLAN.md](docs/IMPLEMENTATION_PLAN.md).
